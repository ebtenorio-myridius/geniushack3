# Supervisory Framework Research Plan

The scoring categories are a prototype and must not be treated as a production control. Before production, the FCRM owner must map the decomposition to published supervisory material, including FFIEC BSA/AML risk assessment guidance, FATF risk-based approach guidance, and applicable sanctions requirements.

The mapping must record:

- source title, publisher, URL, and retrieval date;
- requirement or principle being used;
- category and rule it supports;
- why the rule applies to the change type; and
- analyst approval of the mapping.

The current implementation intentionally exposes `scoring_method` so a versioned, governed rule set can replace the placeholder weights.
