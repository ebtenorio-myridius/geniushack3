# Presentation Pack

This folder contains the presentation outline, live-demo script, judging evidence matrix, and editable Genius Hacks deck.

## Files

- `deck.md` - slide-by-slide presentation content.
- `demo-script.md` - the live demonstration sequence and fallback plan.
- `evidence-matrix.md` - mapping from judging criteria to repository evidence and remaining gaps.
- `Risk_Assessment_Workbench_Genius_Hacks_2026.pptx` - editable presentation deck generated by `tools/generate_presentation.py`.

The generator contains the slide layout and slide copy; it does not parse `deck.md`. Keep the outline, script, and evidence matrix aligned with the generator when updating claims. Evaluation metrics are loaded from `evals/results/latest.json` at generation time.

Regenerate the deck after changing slide content or measured results:

```bash
python tools/generate_presentation.py
```
