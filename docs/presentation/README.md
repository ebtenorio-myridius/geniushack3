# Presentation Pack

This folder contains the presentation outline, live-demo script, judging evidence matrix, and editable Genius Hacks deck.

## Files

- `deck.md` - slide-by-slide presentation content.
- `demo-script.md` - the live demonstration sequence and fallback plan.
- `evidence-matrix.md` - mapping from judging criteria to repository evidence and remaining gaps.
- `Risk_Assessment_Workbench_Genius_Hacks_2026.pptx` - editable presentation deck generated by `tools/generate_presentation.py`.

The generator contains the slide layout and slide copy; it does not parse
`deck.md`. Keep the outline, script, evidence matrix, and generated deck aligned
when updating claims. Evaluation metrics are loaded from
`evals/results/latest.json` at generation time. The generator also runs the
local pytest suite and records its result on the deck.

Regenerate the deck after changing slide content or measured results:

```bash
python tools/generate_presentation.py
```

The prototype includes structured extraction with source citations,
deterministic scoring, a product-owner/analyst/committee workflow, information
requests, conditional approvals, closure and reassessment, retained source
documents, cycle-time reporting, and examiner-style export. Workflow routes
check fixed demo identities and roles, but this is not production
authentication. The event hash chain and source hashes are verifiable but are
not immutable against a database owner. Policy guidance and risk/decision
rules are not institutionally approved, and residual-risk controls are not
modeled. See the evidence matrix for claim boundaries.
