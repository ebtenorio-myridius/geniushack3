# Architecture

Suggested contents (fill in as decisions get made):

- `overview.md` — system diagram, component responsibilities
- `data-model.md` — the governed data layer the brief asks for
- `decisions.md` — a running decision log: what you chose, alternatives
  considered, and why (e.g. "extraction is an LLM call, scoring is
  deterministic — see risk_scoring.py")

Judges read commit history as part of the evidence, so update this
incrementally rather than writing it all at the end.
